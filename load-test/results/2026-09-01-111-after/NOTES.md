# 배포 중 세션 생존 — 운영 after (2026-09-01, #111 IMDS 드레인)

조건은 운영 before(2026-08-30-107-prod)와 동일: fixed 50세션 / SESSION_SEC 600 / PROBE_SEC 2 /
재연결 계약 ON, 세션 수립 후 같은 이미지로 instance refresh. 인스턴스엔 #111(IMDS target-lifecycle-state
2초 폴링 → 등록 해제 시작 시점 드레인) + 핫픽스 적용.

파일: `prod-rolling-50-take4.*`(본 측정), `baseline-no-deploy-50.*`(배포 없는 평상 기준선),
`take3-no-refresh-50.*`(refresh 미트리거 회차 — 기준선 2). 1·2차 시도는 노트북 잠자기/URL 오타로 무효
(교훈: k6는 `caffeinate -i`로).

## 결론

"끊김의 트리거는 SIGTERM이 아니라 ALB 등록 해제"라는 8/30의 발견을 반영한 IMDS 드레인이 운영에서
검증됐다. 배포 1회의 사용자 영향: **세션 사망 0, 소켓당 평균 0.6~1초의 시그널링 공백**(P2P 촬영은 무중단).
남은 항목: 이중 탈출 축소·1대 서빙 구간 제거는 launch-before-terminate(이슈 B), 유실 0.77%는
계약(OFFER 재발신·DEVICE_SPEC 재전송)으로 클라에서 흡수.
